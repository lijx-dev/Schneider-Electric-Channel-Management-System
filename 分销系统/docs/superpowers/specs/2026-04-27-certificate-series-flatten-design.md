# 证书查询页产品系列扁平化设计

## 目标

将证书查询页从当前的：

`企业 -> 证书类型 -> 产品类型 -> 产品系列 -> 详情`

改成：

`企业 -> 证书类型 -> 产品系列 -> 详情`

并在同一证书类型下，把不同旧“产品类型”中名称完全相同的产品系列合并成一个入口，详情页展示合并后的全部详情，不再展示来源分类。

## 约束

- 不改后端现有证书接口。
- 仅按“产品系列名称完全相同”进行合并。
- 合并后的 `count` 为所有来源分类下该产品系列详情数总和。
- 详情页不显示原始第三层分类来源。

## 方案

前端在选中证书类型后：

1. 请求该证书类型下全部分类列表。
2. 逐个请求每个分类下的产品系列列表。
3. 以产品系列名称为键做聚合，生成新的“产品系列”列表。
4. 保存每个聚合产品系列对应的原始分类名数组，供详情页使用。
5. 点进产品系列时，逐个分类请求详情并将结果拼接后展示。

## 影响范围

- 修改证书查询页状态机，移除单独的“分类”页面展示。
- 修改面包屑和页面标题，使其不再出现第三层分类。
- 新增前端聚合 helper 与回归测试。
