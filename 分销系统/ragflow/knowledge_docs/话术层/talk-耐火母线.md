# 耐火母线系列 — 耐火型母线槽

## 核心参数

- 电流范围：—
- 核心卖点：
  - 经耐火包覆构造，满足国标线路完整性试验
  - 火灾规定时限内可持续为消防设备供电

### 耐火标准要求的950℃是指什么

根据新民规（GB51348-2018)13.8.4根据《建筑物电气装置》IEC60364火灾防护的规定，消防配电线路应保证消防设备火灾时持续运行时间的要求，据此本标准提出应按消防设备持续供电时间要求的不同，选用不同耐火等级的电线、电缆或耐火母线槽，条文中的950℃是指火灾现场可能达到的温度也即耐火电缆等产品燃烧时需承受的温度

*来源QA: 019e255e-4eac-741e-b898-588c085b971b*

### 耐火母线槽有哪些主要标准

根据新民规（GB51348-2018)，《母线干线系统（母线槽）阻燃、防火、耐火性能的试验方法》GA/T 537，《耐火母线干线系统(耐火母线槽)》JB/T 10327，《在火焰条件下电缆或光缆的线路完整性试验 第21部分：试验步骤和要求 额定电压0.61.0kV及以下电缆》GB/T 19216.21-2003

*来源QA: 019e2484-4120-7b5f-bf4c-8ff9d5434e35*

## 应用场景推荐

### 行业内关于耐火性能的标准有哪些

建筑类项目中，我们经常遇到的3个耐火性能相关的标准有：
GA/T 537 – 2005《母线干线系统（母线槽）阻燃、防火、耐火性能的试验方法》;
JB/T10327 - 2011《耐火母线干线系统（耐火母线槽）》;
GB/T19216.21-2003 《在火焰条件下电缆或光缆的线路完整性试验 第21部分：试验步骤和要求 额定电压0.61.0kV及以下电缆》;
改版后的JB/T10327-2011完全等同于GA/T537-2005; 相对GB/T19216.21，试验设备、试件要求、试验程序和判定条件都有不同。

*来源QA: 019da954-e200-745b-b249-b5d3de34ca8d*
