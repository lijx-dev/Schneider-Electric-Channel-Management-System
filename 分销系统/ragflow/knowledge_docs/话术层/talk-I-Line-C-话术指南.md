# I-Line C 系列 — 智能化密集型母线槽

## 核心参数

- 电流范围：630A-6000A
- 核心卖点：
  - 整体式接地母线(IGB)结构
  - 高纯度电解铜，全长镀银
  - 防护等级 IP40/IP41/IP54/IP65/IP66
  - 无线温湿度测量、电能监测、EcoStruxure监控平台
  - EZ连接理念，安装便捷
  - 插接箱范围 15A-1600A
- 适用场景：会展、商业楼宇、交通运输、教育科研、电子信息、石化、冶金

## 常见客户疑虑及应对话术

### 说机房或者井道空间很紧，I-LINE C系列有没有优势

有。I-LINE C系列在结构上强调整体式接地母线IGB结构、户外特殊外壳、EZ连接理念，尺寸/重量特点是外形尺寸和附件尺寸覆盖630A-6000A。因此在空间紧凑项目中往往比传统配线方式更容易落地。

*来源QA: 019eca9b-c8f5-7554-9256-d384341ab3cc*

### 特别担心后期运维麻烦，I-LINE C系列应该怎么回答

可以重点讲I-LINE C系列的运维友好性，包括无线温湿度测量、电能监测、COMX BOX、EcoStruxure监控平台和直身段、馈电单元、弯头、安装支架、插接单元、终端封。如果客户要的是可视化管理和预警能力，这类回答通常更有效。

*来源QA: 019eca9b-c8f4-7e10-915a-0413ce16297d*

### 现场有喷淋或者环境偏潮湿，I-LINE C系列还能不能做

这时关键要看防护等级。I-LINE C系列可提供IP40/IP41/IP54/IP65/IP66，并且安全/环境适应能力方面强调了：地线先接后断、三重联锁、户外保护结构、主动运维预警。
