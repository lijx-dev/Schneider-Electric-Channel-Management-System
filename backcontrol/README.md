# 施耐德学堂后台管理

这是新的后台管理系统静态页面，默认调用测试环境：

`https://faq-backend-229183-5-1407839340.sh.run.tcloudbase.com`

## 功能

- 公司员工排行榜：选择公司后查看公司内员工答题排行。
- 账户管理：新建、修改、删除分销商员工账户。
- 答题参与统计：查看周参与名单和月度参加周数，并导出月报 CSV。

## 使用方式

直接部署 `backcontrol` 目录为静态站点即可。管理员账号密码使用后端环境变量：

- `ADMIN_USERNAME`
- `ADMIN_PASSWORD`
- `ADMIN_SECRET_KEY`

如果静态站点域名和后端域名不同，需要在后端 `CORS_ORIGINS` 中加入后台静态站点域名。
